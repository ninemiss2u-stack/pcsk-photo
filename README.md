# PCSK PHOTO

ระบบคัดรูป ปรับแต่งภาพ และใส่ลายน้ำ สำหรับภาพกิจกรรม **โรงเรียนประชาสงเคราะห์วิทยา จังหวัดพิษณุโลก** (งานประชาสัมพันธ์)

ทุกอย่างทำงานในเบราว์เซอร์บนเครื่องของผู้ใช้ **ไม่มีการส่งรูปขึ้นอินเทอร์เน็ต** และไม่แก้ไขไฟล์ในเมมโมรี่การ์ด

## ความสามารถ

- **คัดรูปอัตโนมัติ** จัดกลุ่มภาพที่ถ่ายซ้ำ ๆ เลือกภาพที่คมชัดที่สุด และคัดภาพเบลอออก (ตรวจและแก้ไขเองได้ก่อนบันทึก)
- **ปรับแสงและสีอัตโนมัติ** แก้สีเพี้ยน ปรับความสว่างและช่วงแสง ให้ทุกภาพในชุดโทนใกล้เคียงกัน
- **ลายน้ำ PCSK PHOTO** 3 แบบ (มุมภาพ / เส้นกรอบบาง / กลางภาพ) ปรับตำแหน่ง ขนาด ความเข้มได้
- รองรับไฟล์ **JPG, PNG, WebP และ HEIC จาก iPhone** ถ้าถ่าย RAW+JPG จะคัดลอกไฟล์ RAW คู่กันไปให้
- ไฟล์ที่บันทึกออกมาเป็น `.jpg` ความละเอียดเต็ม เก็บวันเวลาที่ถ่ายและข้อมูลกล้องไว้ ไม่เขียนทับไฟล์เดิมในโฟลเดอร์ปลายทาง

## วิธีใช้

**แบบออนไลน์** เปิดลิงก์ GitHub Pages ของโปรเจกต์นี้ด้วย Chrome หรือ Edge

**แบบในเครื่อง (Windows)** ดาวน์โหลดโปรเจกต์ (ปุ่ม Code > Download ZIP) แตกไฟล์ แล้วเปิด PowerShell ในโฟลเดอร์นั้น

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

เบราว์เซอร์จะเปิดให้อัตโนมัติ (ปกติที่ http://localhost:8090)

1. กด **เข้าสู่การใช้งาน** แล้วเลือกโฟลเดอร์รูป (เช่น `DCIM` ในเมมโมรี่การ์ด) หรือลากมาวาง
2. ตรวจผลการคัด คลิกที่รูปเพื่อสลับ เก็บ / คัดออก
3. ตั้งค่าการปรับภาพและลายน้ำ ดูตัวอย่างบนรูปจริงได้ทันที
4. กด **บันทึก** แล้วเลือกโฟลเดอร์ปลายทาง

## ข้อควรรู้

- ใช้ Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์จะดีที่สุด เบราว์เซอร์อื่นจะได้ผลเป็นไฟล์ `.zip`
- ไฟล์ HEIC ต้องต่ออินเทอร์เน็ตครั้งแรก เพื่อโหลดตัวแปลง ([heic2any](https://github.com/alexcorvi/heic2any))
- ระบบตัดสินจากความคมชัดและแสงเป็นหลัก ยังไม่ตรวจหลับตาหรือองค์ประกอบภาพ ควรมีคนตรวจซ้ำก่อนเผยแพร่
- ควรขออนุญาตก่อนเผยแพร่รูปที่เห็นหน้านักเรียนชัดเจน ตามนโยบายคุ้มครองข้อมูลส่วนบุคคล (PDPA)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเข้าสู่การใช้งาน |
| `cull.html` | หน้าคัดรูป ปรับภาพ ใส่ลายน้ำ |
| `js/config.js` | ชื่อโรงเรียน และข้อความลายน้ำ |
| `js/cull-core.js`, `js/cull-worker.js` | วิเคราะห์ความคมชัด แสง และหาภาพซ้ำ |
| `js/enhance.js` | ปรับแสงและสีอัตโนมัติ |
| `js/watermark.js` | ลายน้ำ และการสร้างไฟล์ใหม่ |
| `js/heic.js` | แปลงไฟล์ HEIC จาก iPhone |
| `img/` | ตราโรงเรียน และโลโก้ PCSK PHOTO |
| `serve.ps1` | เปิดโปรแกรมในเครื่อง |
